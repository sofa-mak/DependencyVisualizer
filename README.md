# DependencyVisualizer (Вариант №13)

Инструмент командной строки (CLI) на языке Python для анализа и визуализации графа зависимостей Java-пакетов (Maven) без использования сторонних менеджеров пакетов.

## Возможности
- Анализ прямых зависимостей пакета через URL репозитория Maven.
- Построение графа зависимостей с помощью алгоритма BFS (поиск в ширину).
- Ограничение глубины анализа.
- Фильтрация пакетов по подстроке.
- Вывод порядка загрузки зависимостей (топологическая сортировка с обработкой циклов).
- Визуализация графа в формате Graphviz (генерация `.dot` и `.png` файлов).
- Вывод графа в виде текстового ASCII-дерева.
- Режим тестирования (чтение графа из локального файла).

## Установка и запуск

Для работы скрипта требуется установленный Python 3. Для генерации PNG-изображений используется библиотека `pygraphviz`.

**Установка зависимостей:**
```bash
pip3 install --trusted-host pypi.org --trusted-host pypi.python.org --trusted-host files.pythonhosted.org pygraphviz
